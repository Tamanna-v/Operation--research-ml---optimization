# Operation Research and Machine Learning for Optimization
##Overview
This project explores the application of machine learning and operation research techniques to optimization and data driven decision making problems.
##Objectives
Formulate an optimization problem.
Apply operation research techniques to the problem.
Explore how Machine Learning can support optimization and decision - making.
Analyze and interpret the result.
##Methods
Operation Research
Mathematical Optimization
Linear Programming
Machine Learning
Python
##Tools
Python and relevant scientific computing and machine learning libraries.
